# CineIR supplementary website

Static publication files. Enable GitHub Pages with **GitHub Actions** as the source.
All videos are stored as complete MP4 files under `site/videos/`.
The long-form sequence is encoded at a reduced bitrate while retaining its full duration, 1080p resolution, and 30 fps frame rate.
The website entry is `site/index.html`; no video reconstruction is required.

This repository alone does not establish an anonymous review link. Verify the limits and playback behavior of any anonymizing proxy separately.
